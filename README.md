# 小米 · Windows 桌宠

小米是一只约 14 斤的长毛橘色虎斑公猫。形象以主人提供的真实照片为依据，采用柔和、偏写实的立体动画风格；日常慵懒好奇，偶尔扑抓玩耍，也喜欢零食。

## 启动

完成打包后，在 `release/Xiaomi-win32-x64/` 文件夹中双击 `Xiaomi.exe`。整个文件夹需一起保留，程序默认不开机自启。右键点击小米可退出。

源码项目位于 `D:\document\Codex\xiaomi-desktop-pet`。

## 操作

| 操作 | 效果 |
| --- | --- |
| 左键点击小米 | 查看 Codex 5 小时额度、周额度及重置时间 |
| 按住至少 0.3 秒并移动鼠标 | 拖动小米到新位置，轻轻挣扎后落稳 |
| 在小米身上悬停 2 秒 | 在附近扑抓鼠标，约 8 秒后休息 |
| 右键 → 玩耍逗猫棒 | 鼠标控制逗猫棒，按 Esc 结束 |
| 右键 → 追逐扑鼠标 | 持续在附近扑抓鼠标，按 Esc 结束 |
| 右键 → 喂零食 | 闻闻、吃零食、舔嘴，没有饥饿惩罚 |
| 右键 → 让小米睡觉 | 睡约 20 分钟后自动醒来，可右键提前叫醒 |
| 右键 → 静音 | 关闭声音，保留讨关注动作 |

清醒时连续 15 分钟没有和小米互动，会轻叫讨关注；之后每 5 分钟再提醒一次。点击、拖动、喂食或玩耍会重新计时。睡觉、持续玩耍、锁屏和电脑休眠期间不播放讨关注提醒。

位置和静音设置保存到程序自己的 Windows 用户数据目录。透明区域可点击穿透，不改变系统鼠标位置。

## 额度

需要先安装 Codex 并登录同一个 ChatGPT 账户。程序使用本机 `codex app-server` 的账户额度读取接口，打开额度卡片时刷新，不创建模型对话。没有登录、连接失败或账户没有返回某项额度时会显示具体状态；旧数据会标明更新时间。

## 小米的叫声

根据主人后续选择，采用罗小黑猫形态的短猫叫，来自《明日方舟》罗小黑联动角色语音的公开社区存档。两个短片段降低音量后组成约 1.24 秒的轻叫，并按试听反馈进一步降低约 6dB、柔化起落，没有进行声音克隆或变调。它是角色音效，不是小米的真实录音。

来源：[Luo Xiaohei cat-form voice archive](https://github.com/PseudoMon/arknights-audio/tree/global-server-voices/voice/char_4067_lolxh)。来源与处理记录保存于 `assets/audio/status.json`，原始素材的权利归各自权利人所有。

主人已确认所给视频没有小米的猫叫。视频原始音轨保存在 `media-analysis/video-audio.wav`，素材观察与说明见 `media-analysis/report.md`。

## 动画与开发

- `assets/animations.json`：桌宠动画清单；额外动画位于 `assets/extra/`。
- `art-run/final/`：Codex 标准 8×9 图集和结构验证结果。
- `art-run/qa/`：联系表、逐动作 GIF、视觉与结构检查结果。
- `pets/xiaomi/`：可交付的 Codex 自定义宠物包。
- `src/`：Electron 主进程、窄接口 preload、精灵画面、行为状态机和额度适配器。

安装 Node.js 后运行：

```powershell
npm install
npm test
npm start
npm run package
```

角色图像使用内置 ImageGen 按原始照片和统一主形象生成。`hatch-pet` 的确定性脚本只负责布局、抠底、提取、校验与打包；`art-tools/` 中的脚本负责额外动作准备和导出，不在本地绘制替代猫咪素材。

`references/` 包含主人提供的私人照片、视频和画风截图，`media-analysis/` 包含分析中间文件。便携程序打包时排除这些目录，仅包含运行所需的图像和已确认音频。
